# UniSolveX

UniSolveX is a frontend-based academic platform designed to provide **Previous Year Question Papers (PYQs)** and their solutions for AKTU and other universities.

This project currently includes a **Landing Page** and an **Admin Panel UI with all controls** for managing academic resources.

Built using **React.js**, **Tailwind CSS**, **SweetAlert2**, and **React Icons**.

---

## Features

### Landing Page
- Clean and responsive design
- Project overview section
- University resource showcase
- Navigation interface
- Professional UI

### Admin Panel
- Dashboard interface
- Add question papers
- Upload solutions
- Edit resources
- Delete resources
- Manage universities and courses
- Alert notifications using SweetAlert2

---

## Tech Stack

- React.js
- Tailwind CSS
- SweetAlert2
- React Icons
- Vite

---

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/UniSolveX.git
```

Go to project folder:

```bash
cd UniSolveX
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
